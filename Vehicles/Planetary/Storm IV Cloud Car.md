The first high-atmosphere airspeeder to be classified as a cloud car, Bespin Motors' Storm IV was built for use by Cloud City's Bespin Wing Guard.

> More information about the vehicle is available on the [Wookieepedia article](https://starwars.fandom.com/wiki/Storm_IV_Twin-Pod_cloud_car).
