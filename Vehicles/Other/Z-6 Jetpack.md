## Z-6 JETPACK

Source: [^1]

![Encumbrance 3 Price 5,250 Rarity 7|377](https://static.wikia.nocookie.net/star-wars-rpg-ffg/images/5/5c/Profile_Z-6_Jetpack.png/revision/latest/scale-to-width-down/800)

> [!quote] Image text

A Z-6 jetpack allows a person to function as a silhouette 1, speed 2, handling 0, system strain threshold 3 vehicle that can only operate in atmosphere and requires [[Piloting - Planetary (Ag)|Piloting (Planetary)]] to operate.[^0-2]

A Z-6 jetpack features an integrated missile launcher with the following profile: ([[Ranged - Heavy (Ag)|Ranged (Heavy)]]; Damage 15; Critical 3; Range \[Long\]; [[Item Qualities#Blast (Active)|Blast]] 10, [[Item Qualities#Breach (Passive)|Breach]] 1, [[Item Qualities#Inaccurate (Passive)|Inaccurate]] 1, [[Item Qualities#Limited Ammo (Passive)|Limited Ammo]] 1, [[Item Qualities#Prepare (Passive)|Prepare]] 1).[^0-2]
