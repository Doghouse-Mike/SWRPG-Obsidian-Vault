This Repo is just an [Obsidian](https://obsidian.md/) Vault containing everything from the FFG SWRPG fandom/wiki.

A bunch of stats got added as frontmatter, meaning Bases, and other tools can use them. Some example Bases are included by default.    
Notes/topics/categories are linked to each other. I accept no responsibility for your rabbit holes. [You do it to yourself](https://www.youtube.com/watch?v=TZnsNexCMg0).          
The Fandom CDN doesn't like you grabbing their images, so they remain online only but *are* fetched as needed. Many have decent alt-text, so the stats are still included, even if the image itself isn't.     

Mostly created via [this script](https://github.com/Doghouse-Mike/fandom2obsidian) plus a little bit of tweaking.     
If something is definitely broken, let me know.
