Much to Learn ability tree

In an era when the Jedi are all but extinct, passing on the scattered remnants of their teachings has become a vital task.

> More information found on page 34 of **[[Category - Consular|Disciples of Harmony]]:** *A Sourcebook for Consulars*.

### BASE ABILITY

Once per game session during an encounter, the character may spend 2 Destiny Points and make a **[[Narrative Dice#Standard Difficulties|Hard difficulty]] [[Education (Int)|Knowledge (Education) check]]**. The character then chooses one talent that \[they\] possess. For the remainder of the current encounter, one allied character within medium range counts as having that talent. If the talent is ranked, the allied character counts as having as many ranks in the talent as the character with the signature ability does.

### UPGRADES

**Change Skill (Knowledge):** When activating Much to Learn, the character may make any [[Category - Knowledge Skills|Knowledge skill]] check instead of a [[Education (Int)|Knowledge (Education)]] check.

**Change Skill (Leadership):** When activating Much to Learn, the character may make a [[Leadership (Pr)|Leadership]] skill check instead of a [[Education (Int)|Knowledge (Education)]] check.

**Destiny:** To activate Much to Learn, the character only needs to spend 1 Destiny Point instead of the normal 2.

**Improve Talent:** If the character possesses the improved version of the chosen talent, allies affected by the Much to Learn base ability also count as having the improved version of the talent.

**Increase Number:** Increase the number of allies affected by the base ability by two per Increase Number upgrade.

**Reduce Difficulty:** The difficulty to activate Much to Learn is **[[Narrative Dice#Standard Difficulties|Average]]** instead of **[[Narrative Dice#Standard Difficulties|Hard]]**.

**Supreme Talent:** If the character possesses the supreme version of the chosen talent, allies affected by the Much to Learn base ability also count as having the supreme version of the talent.
