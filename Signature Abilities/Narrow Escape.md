Narrow Escape ability tree

Whether a smuggling deal has gone south or the authorities see through the ship's fake transponder code, Smugglers frequently find themselves in a position where they need to make a getaway—and fast.

> More information found on page 37 of **[[Category - Smuggler|Fly Casual]]:** *A Sourcebook for Smugglers*.

### BASE ABILITY

Once per game session, the character may spend two Destiny Points to make a **[[Narrative Dice#Standard Difficulties|Hard difficulty]] [[Streetwise (Cun)|Streetwise check]]**. If \[they\] succeed, the character immediately flees from the current personal-scale combat encounter unscathed. The challenge is not overcome or defeated, but the character evades the hazard or threat for the time being. The exact nature of what the character is trying to accomplish, as well as the end results, must be approved by the GM.

When making the skill check to activate Narrow Escape, the GM can add a [[Narrative Dice#Boost (Blue)|boost]] die or [[Narrative Dice#Setback (Black)|setback]] die for any situational effects that might cause the check to be easier or more difficult.

### UPGRADES

**Add Boost Upgrade:** When making the skill check to activate Narrow Escape, the character adds a [[Narrative Dice#Boost (Blue)|boost]] die.

**Change Scale Upgrade:** The character can now perform Narrow Escape on a planetary scale, using [[Piloting - Planetary (Ag)|Piloting (Planetary]] or [[Piloting - Space (Ag)|Space)]] to steer a ship out of trouble (instead of the normal [[Streetwise (Cun)|Streetwise]] skill).

**Change Skill Upgrade:** To activate Narrow Escape, the character can use [[Deception (Cun)|Deception]] to escape from a social encounter (instead of the normal [[Streetwise (Cun)|Streetwise]] skill).

**Destiny Upgrade:** To activate Narrow Escape, the character only needs to spend 1 Destiny Point instead of the normal 2.

**Increase Effect Upgrade:** When triggering Narrow Escape, the ability may also affect an additional number of allied characters. The number of characters \[they\] can help is equal to \[their\] ranks in Cunning times the number of Increase Effect Upgrades purchased.

**Reduce Difficulty Upgrade:** The skill check difficulty to activate Narrow Escape is **[[Narrative Dice#Standard Difficulties|Average]]** instead of **[[Narrative Dice#Standard Difficulties|Hard]]**. The GM can still add a [[Narrative Dice#Boost (Blue)|boost]] die or [[Narrative Dice#Setback (Black)|setback]] die as the situation warrants.

**Reduce Setback Upgrade:** When making the skill check to activate Narrow Escape, the character removes a [[Narrative Dice#Setback (Black)|setback]] die.
