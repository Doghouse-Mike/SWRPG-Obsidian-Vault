Battle Meditation power tree

Some Force users can telepathically guide allies around them, helping them to coordinate and achieve amazing feats.

> More information is available in **[[Category - Way of the Force|*Star Wars* Force and Destiny]]** Roleplaying Game: *Core Rulebook* (page 284).

**Prerequisites:** Force Rating 2 +

### BASIC POWER

Battle Meditation’s basic power allows the Force user to influence and coordinate large groups of allies, guid­ing their actions to help them work as a unified whole. The basic power has one way of spending Force points:

- The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] (◑) to add one automatic [[Narrative Dice#Success|success]] result to all checks made by a number of engaged friendly targets up to \[the user's\] Presence before the end of \[their\] next turn. If the user uses any [[Narrative Dice#Dark Point|Dark points]] to generate [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] (◑) on this check, reduce each target’s Willpower by 1 (to a minimum of 1) until the end of the encounter. The user may not activate this multiple times.

### UPGRADES

**Control Upgrade:** When making a **Battle Meditation power check**, the user may make an **[[Narrative Dice#Standard Difficulties|Easy difficulty]] [[Leadership (Pr)|Leader­ship check]]** as part of the pool. If \[they\] generate enough [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] to activate the power and succeed on the check, \[they\] can telepathically transmit a simple order to each character \[they\] affect with this power. This order is not mandatory, but the recipient comprehends it even if \[they\] do not understand the user’s languages.

**Control Upgrade:** Before attempting to activate this power, the user may suffer 4 strain to change the range of the Battle Meditation basic power to close on the planetary scale rather than engaged on the personal scale, for this use of the power only. If \[they\] do so, activating the range upgrades increases the range of the power by planetary scale range bands.

**Duration Upgrade:** The power gains the on­ going effect: Commit three [[Narrative Dice#Force (White)|Force]] dice after successfully activating the basic power. This power remains in effect on each affected target as long as the target stays within range of the power. If a target moves beyond the range of the power, the effects end for \[them\], but not for any other targets of the power. The user may not activate this multiple times.

**Magnitude Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] (◑) to increase the number of targets af­fected by an amount equal to the us­er’s Presence multiplied by the num­ber of Magnitude upgrades purchased. The user may activate this multiple times, increasing the number of targets by this number each time.

**Mastery Upgrade:** If no [[Narrative Dice#Dark Point|Dark points]] were used to generate a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] (◑) the user may choose one skill; while under the effects of the power, each af­fected character counts as having the same number of ranks in the chosen skill as the affected character with the most ranks in that skill. If any [[Narrative Dice#Dark Point|Dark points]] were used to generate a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] (◑) on this check, each target affected must make an **[[Narrative Dice#Standard Difficulties|Easy difficulty]] [[Discipline (Will)|Discipline check]]** if \[they\] wish to resist obeying any orders given by the user as part of this power.

**Range Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] (◑) to increase the maximum range at which the Force user can affect targets through this power by a number of range bands equal to the number of Range upgrades purchased. The user may activate this multiple times, increasing the range by this number each time.

**Strength Upgrade:** Spend two [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] (◑◑) to add one additional [[Narrative Dice#Success|success]] result to all affected characters' checks. The user may activate this multiple times, adding one additional [[Narrative Dice#Success|success]] result to all checks each time.
