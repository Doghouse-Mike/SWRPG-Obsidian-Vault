Bind power tree

Those strong in the Force can use it to extend their reach beyond their physical capabilities.

> More information can be found on page 44 of **[[Category - Clone Wars Begin|Rise of the Separatists]]:** *An Era Sourcebook* or on page 286 of **[[Category - Way of the Force|*Star Wars* Force and Destiny]]** Roleplaying Game: *Core Rulebook*.

**Prerequisites:** Force Rating 2 +

### BASIC POWER

Bind's basic power allows the Force user to restrain those nearby, preventing them from harming others and themselves. The basic power has one way to spend Force points:

- The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to immobilize a target within short range until the end of the user's next turn. If the user used any [[Narrative Dice#Dark Point|Dark points]] to generate [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] on this check, the target also suffers 1 wound (ignoring soak) per [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] spent on the check. The user may not activate this multiple times.

### UPGRADES

**Control Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to immediately move the target one range band toward or away from the user. The user may not activate this multiple times.

**Control Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]]; whenever a target affected by Bind takes an action, they suffer strain equal to the user's Willpower. The user may not activate this multiple times.

**Duration Upgrade:** The power gains the ongoing effect: Commit three [[Narrative Dice#Force (White)|Force]] dice after successfully activating the basic power. If a target was immobilized or staggered by this power, they remain immobilized or staggered as long as three [[Narrative Dice#Force (White)|Force]] dice remain committed and the target stays within range. If a target moves beyond the range of the power, the effects end for that target, but not for any other targets of the power. The user may not activate this multiple times.

**Magnitude Upgrade:** Spend two [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] increase the number of targets affected by an amount equal to the number of Magnitude upgrades purchased. The user may activate this multiple times, increasing the number of targets by this number each time.

**Mastery Upgrade:** When the user is making a **Bind power check**, if the check was not already opposed, the user may roll an **opposed [[Discipline (Will)|Discipline]] versus [[Discipline (Will)|Discipline]] check** as part of the pool. To activate this upgrade, they must generate enough [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] to activate the power *and* must succeed at the opposed check. If no [[Narrative Dice#Dark Point|Dark points]] were used to generate [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]], the target is also staggered until the end of the user's next turn. If the user succeeds and used any [[Narrative Dice#Dark Point|Dark points]] to generate [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] on this check, the target immediately suffers a Critical Injury with a +10 to the roll per [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] spent on the check.

**Range Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to increase the maximum range at which the Force user can affect targets with this power by a number of range bands equal to the number of Range upgrades purchased. The user may activate this multiple times, increasing the range by this number each time.

**Strength Upgrade:** Spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to disorient the target for a number of rounds equal to the number of Strength upgrades purchased. The user may activate this multiple times, increasing the number of rounds by this number each time.
