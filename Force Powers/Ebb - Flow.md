Ebb/Flow power tree

Some Force users have compared the Force to an ocean.

> More information can be found on page 38 of **[[Category - Consular|Disciples of Harmony]]:** *A Sourcebook for Consulars*.

### BASIC POWER

The basic power can be used either to empower the user or to sap strength from the user's foes. The basic power has two ways to spend Force Points.

- **Ebb:** When the Force user makes a skill check, \[they\] may roll an **Ebb power check** as part of the roll. The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to suffer 1 strain, then inflict 1 strain on all other engaged characters. The Force user may not activate this multiple times.
- **Flow:** When the Force user makes a skill check, \[they\] may roll a **Flow power check** as part of the roll. The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to heal 1 strain. The Force user may not activate this multiple times.

### UPGRADES

**Control:** This control upgrade has different effects for Ebb and Flow.

- **Ebb:** When making a combined Ebb power check, the Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to add a [[Narrative Dice#Threat|threat]] result to all checks made by engaged opponents until the end of the Force user's next turn. The Force user may not activate this multiple times.
- **Flow:** When making a combined Flow power check, the Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to add an [[Narrative Dice#Advantage|advantage]] result to any checks the Force user makes that use the same skill before the end of \[their\] next turn. The Force user may not activate this multiple times.

**Control:** This Control upgrade has different effects for Ebb and Flow.

- **Ebb:** When making a combined Ebb power check, the Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to add a [[Narrative Dice#Failure|failure]] result to all checks made by engaged opponents until the end of the Force user's next turn. The Force user may not activate this multiple times.
- **Flow:** When making a combined Flow power check, the Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to add a [[Narrative Dice#Success|success]] to any checks the Force user makes that use the same skill before the end of the user's next turn. The Force user may not activate this multiple times.

**Control:** The Force power gains the following effect: Once per encounter, spend three [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] to ask a single "yes-or-no" question pertaining to the current events of the game. The GM must answer truthfully (although depending on how the question is phrased, the answer still may be misleading!)

**Control:** The Force power gains the ongoing effect: Commit a [[Narrative Dice#Force (White)|Force]] die until the end of the current encounter. For the remainder of the current encounter, the Force user must add a [[Narrative Dice#Force (White)|Force]] die to all skill checks \[they\] make. Each [[Narrative Dice#Light Point|light point]] and [[Narrative Dice#Dark Point|dark point]] result rolled adds either a [[Narrative Dice#Success|success]] result or [[Narrative Dice#Advantage|advantage]] result to the check (the user's choice). However, for each [[Narrative Dice#Dark Point|dark point]] result rolled, the user suffers 1 strain and gains 1 Conflict.

**Range:** The Force user may spend two [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] to affect all other characters at short range with this power, instead of affecting all other engaged characters.

**Strength:** The Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to increase the strain healed or inflicted by this power by 1. The Force user may activate this multiple times.

**Strength:** The Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to increase the [[Narrative Dice#Advantage|advantage]] result added to \[their\] checks before the end of \[their\] next turn by 1, or increase the [[Narrative Dice#Threat|threat]] result added to engaged characters before the end of \[their\] next turn by 1. The Force user may activate this multiple times.

**Strength:** The Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to increase the [[Narrative Dice#Success|success]] result added to \[their\] checks before the end of \[their\] next turn by 1, or increase the [[Narrative Dice#Failure|failure]] result added to engaged characters before the end of \[their\] next turn by 1. The Force user may activate this multiple times.

**Magnitude:** The Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to exclude a number of engaged characters equal to the number of Magnitude upgrades purchased from being affected by this power. The Force user may activate this multiple times.

**Mastery:** The Mastery upgrade has different effects for Ebb and Flow.

- **Ebb:** Once per session, if a character suffered at least 5 strain from a single use of this power, the Force user may choose to add an automatic [[Narrative Dice#Despair|despair]] result to that character's next skill check.
- **Flow:** Once per session, if the Force user healed at least 5 strain from a use of this power, the Force user may choose to add an automatic [[Narrative Dice#Triumph|triumph]] to \[their\] next skill check.
