Manipulate power tree

While many Force users seek to use their powers to interact with other living beings or enhance their own abilities, some are more attuned to how the Force affects and modifies machinery.

> More information can be found on page 36 of **[[Category - Sentinel|Endless Vigil]]:** *A Sourcebook for Sentinels*.

### BASIC POWER

The Force user shapes machine components on a molecular level, allowing better crafting and repairing of items.

The Force user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to cause one vehicle or starship \[they\] are engaged with to recover one system strain. The user may activate this multiple times, increasing the system strain recovered by one each time.

### UPGRADES

**Control Upgrade:** The power gains the ongoing effect: Commit a [[Narrative Dice#Force (White)|Force]] die. Upgrade the ability of [[Computers (Int)|Computers]] and [[Mechanics (Int)|Mechanics]] checks once. This cannot be activated multiple times.

**Control Upgrade:** When performing a combat check against a droid, ship, vehicle, or other mechanical construct within engaged range, the user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to inflict 1 additional strain or system strain on the target. The user may activate this multiple times, increasing the strain or system strain inflicted by one each time.

**Control Upgrade:** When making a [[Mechanics (Int)|Mechanics]] skill check, the user may roll a Manipulate power check as part of the pool. The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to gain a [[Narrative Dice#Success|success]] or [[Narrative Dice#Advantage|advantage]] result (user's choice) on the check. The user may activate this multiple times, adding additional [[Narrative Dice#Success|success]] or [[Narrative Dice#Advantage|advantage]] results to the check each time.

**Control Upgrade:** The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to heal a number of wounds equal to \[their\] Intellect in an engaged droid. This counts as the use of an [[Emergency Repair Patch]]. The user may not activate this multiple times.

**Control Upgrade:** The power gains the ongoing effect: Commit a [[Narrative Dice#Force (White)|Force]] die. One damaged weapon or item counts as being undamaged. This can be activated multiple times.

**Control Upgrade:** The power gains the ongoing effect: Commit one or more [[Narrative Dice#Force (White)|Force]] dice. Increase the system strain threshold of one vehicle or starship at engaged range by 3 per [[Narrative Dice#Force (White)|Force]] die committed.

**Control Upgrade:** The power gains the ongoing effect: Commit one or more [[Narrative Dice#Force (White)|Force]] dice. Increase the hull trauma threshold of one vehicle or starship at engaged range by 3 per [[Narrative Dice#Force (White)|Force]] die committed.

**Mastery Upgrade:** When performing a Manipulate power check as part of a [[Mechanics (Int)|Mechanics]] skill check, the user may spend two [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|points]] when using the power to gain a [[Narrative Dice#Triumph|triumph]] result on the check. The user may not activate this multiple times.

**Range Upgrade:** The user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to increase the power's range by a number of personal range bands equal to Range upgrades purchased. The user may activate this multiple times, increasing the range by this number each time.

**Strength Upgrade:** When using this power to cause a target to recover strain or system strain or heal wounds, the user may spend a [[Narrative Dice#Light Point|Force]] [[Narrative Dice#Dark Point|point]] to cause the target to recover one additional strain, system strain, or heal one additional wound per Strength upgrade. This may be activated multiple times.
