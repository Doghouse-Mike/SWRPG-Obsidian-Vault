## Bypass Security

Source: [^1][^2]

- **Activation:** Passive
- **Ranked:** Yes
- **Trees:** [[Skip Tracer]] (1), [[Sleeper Agent]] (2), [[Slicer]] (3), [[Thief]] (2)
- **Items:** [[Digital Lockpick]], [[Lockbreaker Hand]]

The character removes a [[Narrative Dice#Setback (Black)|setback]] die per rank of Bypass Security from \[their\] [[Skulduggery (Cun)|Skulduggery]] and [[Computers (Int)|Computers]] skill checks made to disable a security device or open a locked door.

### Improved

Source: [^3][^4]

- **Activation:** Passive
- **Ranked:** No
- **Trees:** [[Slicer (reSpec)]], [[Thief (reSpec)]]

The character may spend three [[Narrative Dice#Advantage|advantage]] results or a [[Narrative Dice#Triumph|triumph]] result from checks to unlock doors or disable a security device to add [[Narrative Dice#Boost (Blue)|boost]] dice equal to ranks of Bypass Security to similar checks in the same system or location this session. The Game Master determines how similar a check must be to qualify.
