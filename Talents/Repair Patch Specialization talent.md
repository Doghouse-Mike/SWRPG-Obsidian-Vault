## Repair Patch Specialization

Source: [^1]

- **Activation:** Passive
- **Ranked:** Yes
- **Trees:** [[Droid Specialist]] (2)

Whenever the character uses an emergency repair patch, the target heals an additional wound per rank of Repair Patch Specialization. The sixth emergency repair patch and beyond each day still have no effect. If the character is a droid, it may use this talent when using a patch on itself.

[^1]: [[Category - Engineer|Fully Operational]]: *A Sourcebook for Engineers* (Page 31)
