## Font of Power

Source: [^1]

- **Activation:** Active (Action)
- **Ranked:** No
- **Trees:** [[Prophet]]

*Force talent.* Once per game session, the character may perform the Font of Power action. For the remainder of the encounter, if the character is a light side user, whenever another Force user within medium range rolls a [[Narrative Dice#Force (White)|Force]] dice, add an automatic [[Narrative Dice#Light Point|light point]] to the results. If the character is a dark side Force user, whenever another Force user within medium range rolls a [[Narrative Dice#Force (White)|Force]] dice, add an automatic [[Narrative Dice#Dark Point|dark point]] to the results.

[^1]: [[Category - Mystic|Unlimited Power]]: *A Sourcebook for Mystics* (Page 32)
