#### GENESYS CONVERSION

The Star Wars Roleplaying game was released in 2013 in form of the *Edge of the Empire Core Rulebook*. Many years later, elements of the Star Wars RPG were revised and improved for the generic setting based *Genesys Core Rulebook*.

One element of criticism in the Star Wars RPG was the vehicle combat. Genesys did improve these rules and most conversions these days use that as a basis. The one we recommend is the *Order 66 Genesys Conversion Rules* from the *Order 66 Podcast*.

As such, some talents that are a part of the reSpecialized project need to be specially adapted for use with the Genesys system.

Any talents that require an errata when using rule sets that implement the Genesys rules are marked with a bar and circle logo.

```
Improved Signature Ability: Increase that vehicle's top speed by 1, to a maximum of Speed 5.
```
