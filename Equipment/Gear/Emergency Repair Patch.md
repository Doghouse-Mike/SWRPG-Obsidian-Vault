Composed of a semi-flexible durasteel disk coated on one side with insulation and edged with auto-activating thermal welds, emergency repair patches are used to keep machinery running until proper repairs can be done.

> More information about the gear available on the [Wookieepedia article](https://starwars.fandom.com/wiki/Emergency_repair_patch).

**Models Include:** SoroSuub Pocket Tech.

Emergency repair patches are one use items that grant the normal bonus \[of being The Right Tool for the Job\].[^0-1][^1-4][^2-5][^3-6]

Likewise, droids can use them to heal wounds in a manner similar to the way an organic being employs a [[Stimpack|stimpack]]. Using an emergency repair patch requires a character to spend a maneuver. When applied to droids, emergency repair patches heal 3 wounds, and up to five patches can be used in a single day. Using a sixth emergency repair patch has no effect; by that point, the droid is so patched and jury-rigged together that further patches would be useless. It takes one day for a droid's self-repair routines, or actual repairs, to restore its body to enough functionality to be able to gain benefit from additional emergency repair patches.[^0-1][^1-4][^2-5][^3-6]
