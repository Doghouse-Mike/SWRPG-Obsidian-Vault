## SYNOPTIC TEACHER

Source: [^1]

![Encumbrance 1 Price 8,500 Rarity 4|377](https://static.wikia.nocookie.net/star-wars-rpg-ffg/images/2/23/Profile_Synoptic_Teacher.png/revision/latest/scale-to-width-down/800)

> [!quote] Image text
> Encumbrance 1 Price 8,500 Rarity 4

A synoptic teacher is preconfigured to teach a single skill at rank 3. A character using it must make a **[[Narrative Dice#Standard Difficulties|Hard difficulty]] [[Discipline (Will)|Discipline check]]**. Success means the user counts as having that skill at rank 3 for the remainder of the game session. Failure means the user's strain threshold is halved for the remainder of the session instead. The GM can spend a [[Narrative Dice#Despair|despair]] result to cause the synoptic teacher to inflict minor neural scarring, at which point the character can no longer use the synoptic teacher.[^2]
