"TacNet" is a catchall term used by Alliance technicians.

## TACNET TACTICAL DATA NETWORK

Source: [^1]

![Encumbrance - Price 1,000 Rarity 3|377](https://static.wikia.nocookie.net/star-wars-rpg-ffg/images/c/cb/Profile_TacNet_Tactical_Data_Network.png/revision/latest/scale-to-width-down/800)

> [!quote] Image text
> Encumbrance - Price 1,000 Rarity 3

A character can access and utilize the TacNet by making an **[[Narrative Dice#Standard Difficulties|Average difficulty]] [[Computers (Int)|Computers check]]**. If the check is successful, the character using the TacNet removes a [[Narrative Dice#Setback (Black)|setback]] die from all [[Leadership (Pr)|Leadership]] checks \[they\] make until the end of the encounter. In addition the character may spend two [[Narrative Dice#Advantage|advantage]] results or a [[Narrative Dice#Triumph|triumph]] result to add a [[Narrative Dice#Boost (Blue)|boost]] die to all [[Leadership (Pr)|Leadership]] checks \[they\] make until the end of the encounter while using the TacNet to direct \[their\] comrades.

[^1]: [[Category - Commander|Lead by Example]]: *A Sourcebook for Commanders* (Page 49)
