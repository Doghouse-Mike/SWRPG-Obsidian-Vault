While not recommended, most components on a podracer have built-in safety limits that prevent them to break down early or just go up in flames. But like all limits, it is possible to bypass them and overclock performances on a per component basis, for instance increasing engine rpm or enriching the fuel mixture to dangerous levels. This kind of modding can prove extremely expensive the more a racer resorts to using it, damaging components and valuable pieces in the process, which is a true mechanic’s nightmare.

## VERSATILE OVERCLOCK MODULE

Source: [^1]

![Hard Points Required 1 Encumbrance - Price 650 Rarity 3|400](https://static.wikia.nocookie.net/star-wars-rpg-ffg/images/b/be/Profile_Versatile_Overclock_Module.png/revision/latest/scale-to-width-down/800)

> [!quote] Image text
> Hard Points Required 1 Encumbrance - Price 650 Rarity 3

**Models Include:** Various handmade modifications. \
**Base Modifiers:** As an Incidental, may unlock safeties for any number of Components. Each affected Component performs one rank better, but immediately suffer from one rank of [[Item Qualities#Sunder (Active)|Sunder]], renewed each turn as long as the Component stays overclocked. Components must first be modded before being eligible for use with this Attachment.\
**Modification Options:** 1x Engines overclock (Top Speed),1x Boost overclock, 1x Injection overclock (Acceleration), 1x Repair module overclock, 1x Cooling system overclock.
