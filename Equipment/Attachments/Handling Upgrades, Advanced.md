This modification is essentially based on the former [[Handling Upgrades, Improved|Improved]] version, and takes it to another level with the addition of multiple holo systems, upgraded user interfaces and electronics. Some models can also include limited software capability able to accompany the pilot or relieve them of the most intensive menial tasks so they can focus on piloting.

```
This is a homebrew adjustment of an existing [[Handling Upgrades|attachment]] for use with a community-produced homebrew sourcebook!
```
