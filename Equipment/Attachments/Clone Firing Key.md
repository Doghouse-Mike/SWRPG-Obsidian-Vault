One of the early initiatives the Kaminoans considered when developing equipment for the clone troopers was to code their equipment specifically to the clone genetic sequence, to prevent looting and sabotage.

> More information about the attachment available on the [Wookieepedia article](https://starwars.fandom.com/wiki/Clone_firing_key).

## CLONE FIRING KEY

Source: [^1]

> [!quote] Image text

This attachment can be installed on any personal blaster weapon.

**Models Include:** Proprietary Kaminoan design.\
**Base Modifiers:** The weapon functions only in the hands of a clone.\
**Modification Options:** 1 reprogram authorized user genetic sequence (choose one non-clone character) Mod.
